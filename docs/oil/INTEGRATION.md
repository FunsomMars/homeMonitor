# 油价监控集成方案

> 家庭监控系统扩展模块：在现有 `home-monitor` 服务中新增"国内油价历史 + 最新油价监控曲线"页面。
> 设计原则：**复用现有 stdlib + SQLite 风格，不引入 Django / MySQL / Celery / 构建链**。

---

## 1. 集成目标

| 目标 | 描述 |
|---|---|
| 油价趋势页面 | 省份选择 / 油品选择 / 时间范围筛选 / 价格曲线 / 涨跌幅统计 / 最新调价信息 |
| 与温湿度页签共存 | 独立路由 + 独立导航分组 + 统一布局 + 公共组件复用 |
| 数据可追溯 | 来源、更新时间、生效时间全部持久化 |
| 温湿度零回归 | 原有 `web/index.html`（温度页）逻辑完全保留，仅改路径 |

---

## 2. 集成方式（导航 + 路由 + 布局）

### 2.1 路由表（前端三页 + 后端 5 端点）

| 路径 | 类型 | 名称 | 说明 |
|---|---|---|---|
| `/` 或 `/dashboard` | 页面 | 概览壳 | Tab 导航 + 入口卡片，iframe 加载子页 |
| `/temp` | 页面 | 温度监控 | **原 `web/index.html` 整体迁入** `web/temp.html` |
| `/oil` | 页面 | 油价监控 | 新增 `web/oil.html` |
| `/api/health` | API | 健康检查 | 已有 |
| `/api/oil/current` | API | 当前油价（按省份） | 新增 |
| `/api/oil/history` | API | 历史曲线 | 新增 |
| `/api/oil/adjustments` | API | 调价事件 | 新增 |
| `/api/oil/map` | API | 全国地图色阶 | 新增 |
| `/api/oil/refresh` | API | 手动触发抓取 | 新增（需 token） |

### 2.2 导航分组

```
┌───────────────────────────────────────────────┐
│  家庭监控中心                  [v1.1 · 在线]   │
│  ┌─────────┬─────────┬─────────┐               │
│  │ 概览    │ 温度监控 │ 油价监控 │ ← Tab 高亮  │
│  └─────────┴─────────┴─────────┘               │
│  ┌─────────────────────────────────────────┐  │
│  │  iframe: /temp  或  /oil                │  │
│  └─────────────────────────────────────────┘  │
└───────────────────────────────────────────────┘
```

实现：壳页 `web/index.html` 仅含 Tab + iframe，子页独立刷新（温湿度 10s / 油价 30s，互不干扰）。

### 2.3 统一布局与公共组件

- 复用同一套 CSS 变量（`--ink` / `--muted` / `--line` / `--accent` / `--warm` / `--card` / `--bg`）
- 复用同一套卡片样式 `.card`、按钮 `.btn`、表格 `.tbl`
- 公共组件提取为 `web/common.css`（`web/temp.html` 与 `web/oil.html` 各自 link）
- 公共 fetch 封装 `web/common.js`（带超时 + 错误降级）

### 2.4 权限与会话

- 现状：服务仅监听 `127.0.0.1`，无登录系统
- 维持现状：所有 `/api/oil/*` 同样仅本机访问
- `ingest_token` 机制沿用，仅 `/api/oil/refresh`（写操作）需 token，读操作不需
- v1 **不引入** 用户系统

## 3. 功能模块（油价页面）

| 模块 | UI 控件 | 数据来源 | 交互 |
|---|---|---|---|
| 省份选择 | `<select>` 31 省 | 静态列表 | 切换后刷新当前价 + 历史 |
| 油品选择 | 4 按钮 (92/95/98/0) | 静态 | 切换后刷新当前价 + 历史 |
| 时间范围 | 4 按钮 (1月/3月/1年/全部) | — | 切换后刷新历史 + 涨跌幅 |
| 价格曲线 | ECharts Line | `/api/oil/history` | 折线 + 调价日竖线 + 数据缩放 |
| 涨跌幅统计 | 数字卡片 | 本地计算 | 显示区间首末差值、百分比 |
| 最新调价信息 | 卡片 | `/api/oil/adjustments` | 显示最新一次调价的吨价变化、来源、生效时间 |
| 全国地图 | ECharts Map | `/api/oil/map` | 31 省按 92# 色阶着色（红=高 绿=低） |
| 数据源状态 | 折叠面板 | `/api/health` | 显示各抓取源最近一次状态 |

## 4. 数据采集与存储

### 4.1 数据源选型

| 源 | 用途 | 优先级 | v1 状态 |
|---|---|---|---|
| 江苏省发改委 | 92/95/0 当前价 | 最高 | 真实抓取（带降级） |
| 国家发改委 | 调价事件监测 | 最高 | 真实抓取（带降级） |
| 东方财富 | 历史油价 | 中 | 真实抓取（带降级） |
| 中石化/中石油 | 98# 补充 | 低 | v1 用 seed 占位 |
| 本地 seed JSON | 兜底 | — | **保证首日有数据** |

**降级策略**：抓取失败 → 使用上次成功快照 → 仍失败 → 使用 `data/seed/*.json` 静态数据。

### 4.2 定时任务频率

| 任务 | 周期 | 触发器 |
|---|---|---|
| 东方财富历史同步 | 24h | 服务内 `OilScheduler` 守护线程 |
| 江苏发改委当前价 | 6h | 同上 |
| 国家发改委调价监测 | 24h | 同上 |
| 数据完整性自检 | 24h | 同上 |
| 手动触发 | 任意 | `POST /api/oil/refresh` |

**不引入 Celery**：现有服务是 stdlib 单进程，后台 `threading.Thread(daemon=True)` 完全够用。

### 4.3 本地数据表结构

数据存储在 `data/oil.db`（**与 `telemetry.db` 物理隔离**，温湿度路径零影响）。

详见 `docs/oil/SCHEMA.md`。

### 4.4 API 接口形态

详见 `docs/oil/API.md`。
